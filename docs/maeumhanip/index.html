마음한입 개인정보 처리방침

시행일: 2026년 10월 30일

CowComUniverse(이하 운영자)는 마음한입 앱을 운영합니다. 개인정보 관련 문의와 열람·정정·삭제 요청은 cow_com_ai@protonmail.com으로 보내주세요.

1. 처리하는 정보와 목적

  • 기기 내 기록: 사용자가 입력한 두 단어, 앱 설정, 생성된 이야기를 앱 기능 제공을 위해 이용자 기기에 저장합니다. 앱 데이터 삭제 또는 앱 제거 시 기기 기록이 삭제될 수 있습니다.
  • 이야기 생성: 요청한 주기의 단어와 생성 설정(언어, 분량·장르 등)을 Supabase Edge Function을 거쳐 OpenRouter 및 요청에 선택된 모델 제공자에게 보내 이야기를 생성합니다. 생성 Function은 입력이나 결과를 앱의 기록 데이터베이스에 저장하지 않고, 결과는 기기에 보관합니다. 각 제공자의 서비스 로그와 모델 처리·보유 조건은 해당 제공자 설정 및 정책을 따릅니다.
  • 익명 인증 및 요청 제한: 앱은 이메일·전화번호 없이 Supabase 익명 사용자를 생성합니다. 익명 사용자 ID, 시간 단위 요청 횟수와 시각을 이야기 요청 남용 및 생성 비용 제한에 이용합니다.
  • 이야기 신고: 신고 대상 이야기의 ID·제목·본문, 신고 사유와 익명 사용자 ID를 Supabase에 저장해 검토합니다. 신고는 사용자당 하루 최대 5건으로 제한합니다.
  • 광고: Google Mobile Ads SDK와 광고 파트너가 광고 제공, 성과 측정, 진단 및 부정 사용 방지를 위해 IP 주소, 광고 식별자, 기기 정보와 광고·앱 상호작용 정보를 처리할 수 있습니다. 처리 항목은 SDK 버전, 기기, 지역과 광고 설정에 따라 달라질 수 있습니다.
  • 식사 알림: 식사 알림은 기기에서 예약하는 로컬 알림입니다.

2. 제3자 서비스 및 국외 처리

이야기 생성과 신고에는 Supabase, AI 글 생성에는 OpenRouter와 요청 시 선택된 모델 제공자, 광고에는 Google Mobile Ads 및 광고 파트너가 사용됩니다. 관련 정보는 대한민국 밖에서 전송·처리될 수 있습니다. Supabase 데이터베이스의 저장 리전은 FeedForStory 프로젝트 설정을 따르며, Edge Function과 모델 제공자의 처리 위치는 서비스 설정 및 요청 경로에 따라 달라질 수 있습니다.

3. 보유 기간과 파기

  • 기기 기록: 앱 데이터 또는 앱을 삭제하면 기기에서 삭제됩니다.
  • 이야기 생성 요청 제한 기록: 익명 사용자 ID와 시간 단위 요청 횟수·시각은 마지막 사용 시점부터 최대 약 72시간 보관한 뒤 자동 삭제합니다.
  • 신고 요청 제한 기록: 익명 사용자 ID와 날짜별 신고 횟수는 마지막 사용 시점부터 최대 약 72시간 보관한 뒤 자동 삭제합니다.
  • 신고 자료: 신고된 이야기와 사유, 신고자 ID는 검토를 위해 최대 89일 보관합니다. 일일 파기 작업에 따라 실제 삭제까지 최대 약 90일이 걸릴 수 있습니다.
  • 익명 인증 계정: 익명 Supabase 사용자 ID는 서버 요청 인증을 위해 보관됩니다. 앱 제거만으로 서버 계정이 자동 삭제되지는 않으며, 삭제 요청은 문의 이메일로 접수할 수 있습니다.
  • 제공자 운영 로그: Supabase, OpenRouter, 모델 제공자와 Google이 서비스 운영을 위해 처리하는 로그는 각 제공자의 보유·삭제 정책과 설정에 따릅니다.

요청 제한 기록과 신고 자료의 자동 파기는 Supabase 운영 프로젝트에 보유 기간 설정을 적용한 뒤 작동합니다. 법령에 따른 보존 의무가 있는 경우에는 해당 정보를 별도 보관하고 의무 기간이 끝난 뒤 파기합니다.
